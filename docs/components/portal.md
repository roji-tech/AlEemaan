# Parent and student portal — Components

`src/components/portal/`: the screens of `/portal`, which has its own session and its own API routes ([`../functions/portal.md`](../functions/portal.md)).

## `src/components/portal/`

The tabs and sign-in card of the parent and student portal page (`/portal`), all client components fed by `src/app/portal/page.tsx` from the `/api/v1/portal/...` routes, none using the staff session.

| File | Description |
| --- | --- |
| `PortalFinanceTab.tsx` | Client component: the "Fees & Billing" tab (props `invoices`, `student`). Totals invoiced, paid and outstanding are summed in the browser from the invoices; an invoice table and a payment-history table built from each invoice's `payments`. "Pay / View" and "Receipt" only open a modal with bank-transfer or bursary instructions quoting the admission and invoice numbers: the tab never calls a payment endpoint. Every payment's status is drawn with the same green badge. |
| `PortalFormsTab.tsx` | Client component, prop `studentId`: the pupil's "Forms" tab (Task 0041, slice F3) with the sections Practice sets, Questionnaires and Paper work through `SectionTabs`. Offered to a pupil only: `portal/page.tsx` shows the tab when the sign-in's actor is `PUPIL` and may open the overview, because every portal forms route answers a guardian 403. |
| `PortalHeader.tsx` | Client component: the sticky top bar (props `students`, `selectedStudentId`, `onSelectStudent`, `onSignOut`) with the selected pupil's branch name, a "Viewing Child" `<select>` when the session has more than one pupil, and a Sign Out button (one for phones, one for wider screens). |
| `PortalLmsTab.tsx` | Client component: the "Coursework (LMS)" tab from the `/lms` response (props `lms`, `student`, `canSubmit`, `canQuiz`, `onChanged`; hand-in buttons only with `canSubmit`, the whole Quizzes card only with `canQuiz`). Lists assignments (status, score, teacher feedback, a hand-in dialog with text and one optional link), quizzes (a dialog that draws the questions, counts down `timeLimitMinutes` in the browser and submits what is answered at zero) and materials. Posts to the portal `submission` and `attempt` routes, then calls `onChanged`. "Read Lesson" is plain text: materials show three clamped lines and no attachments. |
| `PortalLoginCard.tsx` | Client component: the sign-in card with two tabs, "Admission Number" (admission number plus date of birth or guardian phone) and "Access Token / Link". Posts to `/api/v1/portal/session`, shows the server's message on failure and hands `{ student, siblingStudents }` to `onSuccess`. `initialToken` (the page's `?token=`) preselects the token tab and fills it without submitting. Also exports `PortalStudentRecord`, the pupil type the other tabs use. |
| `PortalOverviewTab.tsx` | Client component: the "Overview" tab (props `overview`, `onNavigateTab`, `tabs`; the fee card is drawn only when the server sent `finance`, and a button to a section the sign-in cannot open is not shown). Pupil card (name, admission number, class and session), attendance rate (green from 80 percent), fee balance with Clear or Balance Due, a static "Active Term" badge with the guardian's name, and the latest announcements; buttons jump to the results, fees and coursework tabs. |
| `PortalPaperWork.tsx` | Client component, prop `studentId`: the paper work set for the pupil's class (`GET .../forms/paper-work`) with the pupil's own state (Not handed in yet, Handed in, Handed in late, You asked your teacher to mark it, Closed: not handed in, or not on the roll call yet) and the closing time, and "Request marking" while the form is published and the pupil's state is pending and they have not asked (`POST .../paper-work/{id}/request-marking`; the API's refusal is shown in words). Empty: "No paper work has been set for you." |
| `PortalPracticeSets.tsx` | Client component, prop `studentId`: the practice sets open for the pupil's class (`GET /api/v1/portal/students/{id}/forms/practice-sets`) with the state of each (Not started, In progress, Finished) and "Start", "Continue" or "See result". The attempt and the result each take the whole tab (`PracticeAttempt`, `PracticeResult`); the list is read again when it is shown. Empty: "No practice sets are open for you right now." |
| `PortalQuestionnaires.tsx` | Client component, prop `studentId`: the questionnaires addressed to the pupil (`GET .../forms/questionnaires`), each with "Answer" or an "Answered" badge. "Answer" opens a dialog that loads the questions (`GET .../questionnaires/{id}`), says in a sentence whether the questionnaire is anonymous, draws the fields with `AnswerFields` and sends `POST .../submit`. Empty: "No questionnaires are waiting for you." |
| `PortalResultsTab.tsx` | Client component: the "Academic Results" tab (props `reportCards`, `student`, `blockedByUnpaidFees`, `outstandingBalance`, `onNavigateToBilling`). When blocked it shows only a restriction card with the balance, or, when the server sent no amount (the sign-in may not see fees), the words "not available yet" and no way to the invoices. Otherwise a term selector and the report card (CA, exam, total, grade, remark, total and average); "Print Card" calls `window.print()`, "Download Card" builds a card in the browser for `downloadReportCardHtml` (no position or class size; the summary assumes 100 marks per subject). Where no remark was written it shows a generic placeholder sentence in the teacher's or principal's box. |
| `PracticeAttempt.tsx` | Client component, props `studentId`, `set`, `onSubmitted(responseId)`, `onLeave`: a pupil's attempt. Opens or resumes it (`POST .../start`) and reads the questions without their key (`GET .../practice-sets/{id}`), draws the fields with `AnswerFields`, and counts "Time left" down (`role="timer"`, said aloud politely at five minutes, one minute and zero) from the moment the attempt started, so leaving and coming back gives no more time. "Submit" sends `POST .../submit` `{ responseId, answers }`; at zero what is on the screen is sent once. A refusal (the server allows a minute more than the limit) is shown in words and the answers stay. "Leave" asks first, because the answers on the screen would be lost. |
| `PracticeResult.tsx` | Client component, props `studentId`, `formId`, `responseId`, `onBack`: the result of an attempt from `GET .../responses/{responseId}`, as the API lets the pupil see it. A machine-marked answer shows Correct or Not quite, its score, the correct answer when it was wrong and the explanation; an answer waiting for the teacher says so and shows no score and no key; the total is "Score so far" while any answer waits, with how many, and "Your score" after. Teacher feedback is shown when there is some. "Download PDF" asks `GET .../print?format=json` and saves the PDF. |
